# simple-control-diagram-simulator-for-students
This is my tesis project, the idea is to create a enviroment where students can experiment with simple control diagrams to help them better understand how they work, we're working with a small sample of only a few diagrams provided by our teacher.

The time frame for this is three months and I have no prior experience with godot, however, I chose godot because it provides an easy way to handle the interactions between objects, the gui elements and to practice videogame developtment concepts.
